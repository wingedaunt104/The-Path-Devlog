# The Path

The Path is a 3D parkour platformer currently in development in Unreal Engine 5.

This repository documents the development of the game, including gameplay systems, level design progress, visual improvements, bug fixes, and future demo releases.

## About the Game

The Path is a multi-level 3D parkour game focused on movement, environmental hazards, checkpoints, and atmospheric level design.

Players progress through distinct environments connected through a central hub, with each level introducing new traversal challenges and visual themes.

## Features

- Third-person parkour movement
- Sprinting, wall-running, and mantling
- Checkpoint and respawn systems
- Autosave and manual save slots
- Central hub with level progression
- Moving and collapsing platforms
- Dynamic environmental hazards
- Niagara visual effects
- Dynamic lightning and storm systems
- Custom menus and UI
- Blueprint and C++ gameplay systems

## Current Development

### Storming Peaks

Storming Peaks is a high-altitude level featuring:

- Floating islands
- Volumetric storm clouds
- Dynamic lightning
- Blue burning flames in wreckage
- Ancient ruins
- Parkour-focused environmental hazards
- Dynamic rain
This level is currently in active development.
